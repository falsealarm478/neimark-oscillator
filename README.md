# Осциллятор Неймарка

Автономная интерактивная лаборатория по модели из **FPAllbook.pdf, § 8.3, стр. 75–76**. Интерфейс на русском и английском языках. Переключатель RU / EN расположен вверху страницы; выбор сохраняется в браузере. Переключение не сбрасывает опыт. Работает без сети, сборки, сервера и сторонних библиотек.

[Открыть лабораторию](https://falsealarm478.github.io/neimark-oscillator/) · [Репозиторий](https://github.com/falsealarm478/neimark-oscillator)

## Версия для учебной презентации

При открытии показывается титульный экран с разделами «Презентация», «Теория по теме», «Авторы» и «Выход». Режим «Показ на проекторе» на широком экране располагает движение и три графика одновременно; параметры открываются кнопкой «Настройки опыта». Добавлены крупные контрастные подписи, более толстые линии графиков, полноэкранный режим и обозначения безразмерных единиц `[1]` на осях. Интерфейс RU / EN работает во всех разделах.

Авторы: Григорьев Александр Сергеевич и Журавлёва Светлана Викторовна. МГУ имени М. В. Ломоносова, факультет вычислительной математики и кибернетики. Руководитель: Ольга Александровна Чичигина.

**Для окончательной сдачи ещё нужна:** проверка на компьютере преподавателя с проектором. Фотографии авторов и эмблемы МГУ и ВМК добавлены. Реальная читаемость с расстояния 10 м и совместимость со старыми версиями Windows не проверены.

## Запуск

Скачайте [готовый архив для запуска](https://falsealarm478.github.io/neimark-oscillator/neimark-oscillator.zip), распакуйте его целиком и дважды нажмите **Осциллятор неймарка.html**.

```text
Осциллятор неймарка.html   ← откройте этот файл
files/          ← код, фотографии и остальные файлы проекта
```

Папку `files` оставьте рядом с файлом запуска. Установка и интернет не нужны — достаточно современного браузера на Windows, macOS или Linux. Не открывайте файл внутри ZIP: сначала извлеките весь архив.

Для Windows x64 также доступен `files/Neimark.exe`. Он открывает соседний `index.html` в браузере, не требует .NET, Python или Node.js.

Для разработчиков: **Code → Download ZIP** скачивает исходный репозиторий. В нём запуск через `index.html`, а готовый архив с простой структурой пересобирается командой `powershell -ExecutionPolicy Bypass -File package-offline.ps1`. Исходный репозиторий одновременно обслуживает GitHub Pages.

## Что показано

- Одномерный осциллятор: пружина, частица, стрелка скорости, вспышка при ударе.
- Фазовая траектория `(x, v)`, мгновенные скачки и точки сечения `x = 0`.
- Синхронный график `v(t)` с общей шкалой скорости и пунктирной проекцией.
- Отображение за полпериода: точные ветви функции и наблюдаемые пары `(vₙ, vₙ₊₁)`.
- Настройка δ, a, h, начальной скорости, три сценария, пауза, сброс, шаг на π, темп анимации, экспорт точек CSV.

«Старт» сбрасывает и запускает опыт; «Пауза» сохраняет состояние; «Стоп» завершает расчёт с сохранением графиков, продолжение возможно после нового старта или сброса. Переход между разделами ставит расчёт на паузу. «Выход» останавливает расчёт и показывает завершающий экран; закрыть открытую пользователем вкладку браузер автоматически не разрешает. Пробел включает паузу вне элементов управления в лаборатории. Изменение физического параметра сбрасывает опыт. «Шаг на полпериода» останавливает воспроизведение и продвигает время ровно на π от текущего момента. Все величины безразмерные.

## Модель и точность

Между ударами:

```text
x'' - 2δx' + (1 + δ²)x = 0
x(s) = vₙ exp(δs) sin(s)
v(s) = vₙ exp(δs) [cos(s) + δ sin(s)]
```

Здесь `s` — время с последнего пересечения `x = 0`, `vₙ` — скорость непосредственно после возможного удара. Начальное состояние: `x₀ = 0`, `v₀` берётся с ползунка и считается уже заданным состоянием после возможного начального импульса.

При следующем пересечении через `π`:

```text
q = exp(πδ)
v_before = -q vₙ
vₙ₊₁ = v_before - h, если v_before > a
vₙ₊₁ = v_before,     если v_before <= a
```

Это именно одностороннее правило учебника, не условие `|v| > a`. Принята конвенция `Θ(0) = 0`. Удар применяется один раз на пересечение, включая случай изменения знака скорости. При нулевой скорости в нулевой координате движение останавливается, фиктивные пересечения не добавляются.

Численное интегрирование Эйлером не используется. Время каждого события вычисляется точно как `nπ`, между событиями берётся аналитическое решение; дискретизация не более 0.025 нужна только для рисования кривой. Скачки рисуются отдельными оранжевыми отрезками.

Фазовый след содержит 24 последних полупериода, график времени — 8. Хранятся до 2000 последних пар отображения, они же выгружаются в CSV. Масштаб автоматически увеличивается, не уменьшаясь во время опыта. При `|x|` или `|v| > 10000` симуляция приостанавливается с сообщением. Для некоторых параметров амплитуда действительно не ограничена. Скрытая вкладка и открытая справка приостанавливают продвижение модельного времени.

Теоретический раздел объясняет модель, единицы, удары и отображение, со ссылками на предоставленные материалы. Корреляционная функция и обсуждение случайности/бифуркаций не включены согласно исходному заданию. Исходный PDF не распространяется вместе с проектом.

## Проверка физики

Только для разработчика требуется Node.js:

```sh
node physics.test.cjs
```

Проверяются аналитическое движение, 400 последовательных переходов, точное пороговое условие, изменение знака при ударе, неподвижное состояние, независимость от кадров анимации и величина скачка.

## Публикация на GitHub Pages

1. Загрузите файлы в новый репозиторий GitHub (в корне должен находиться `index.html`).
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.
4. После завершения публикации GitHub покажет адрес приложения.

Никаких API-ключей, переменных окружения или платного хостинга приложению не нужно.

## Windows-лаунчер

`launcher.c` — исходный код, `build-windows.ps1` — сборка с GCC для Windows (MinGW-w64). Только разработчику нужен компилятор. Полученный EXE использует KERNEL32.dll, SHELL32.dll и USER32.dll — системные библиотеки Windows. Проверены сборка и импортируемые DLL; запуск самого EXE на компьютере преподавателя ещё необходимо проверить.
